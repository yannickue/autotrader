# AR2 reference candidates (12k-bar slice)

`golden.pkl` holds the candidate lists of all 22 AR2 strategy variants generated by the ORIGINAL
(pre-optimization) code on `dev_frame(...).iloc[46000:58000]` (Train->Validation boundary, no OOS).
1311 candidates; generation took 90.9 s with 6 workers. `golden.py check` regenerates and requires
exact equality (dataclass ==). Used as the migration/equivalence gate for the fast research engine.
The paths inside `golden.py`/`equiv.py` point to the original scratchpad and must be adapted.
